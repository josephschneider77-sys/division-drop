## Full description
Division Drop is a bright, kid-friendly falling-block game where math is a power-up — not a gate.

Stack colorful emoji charms, clear lines, and when a glowing ÷ brick appears, tap it to solve a division problem and power-clear blocks.

Made for families practicing 3rd-grade division:
• Big on-screen controls (great for tablets)
• Optional math — kids can just stack if they want
• Gentle speed ramp as the game goes on
• No ads, no chat, no in-app purchases

Portrait mode works best. Install once and play offline after the first load (PWA / TWA caching).
